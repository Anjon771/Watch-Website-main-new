# Tissot Watches and Co. — React Application

An elegant React application showcasing the legacy and collection of **Tissot Watches and Co.**, rewritten from the original static web project into a modern, responsive single-page application built with React 19, TypeScript, Vite, and Tailwind CSS.

## Features

- **Home Page**: Aviation heritage quotation, brand history and Powermatic 80 technology introduction, high-resolution His & Her showcase, and immediate browse access.
- **About Page**: Embedded official Tissot watchmaking video (`tissotvideo.mp4`), interactive know-how breakdowns (Sapphire crystal, High-tech Ceramic, Tactile T-Touch sensors, Water Resistance testing), and detailed 4-column Swiss heritage articles (Le Locle 1853, Sporting Accuracy, Style Meets Function, A Quest for Excellence).
- **Latest Collection**: Interactive digital boutique catalog of 36 authentic Tissot watch models ported directly from the original dataset, featuring search, category filters (Men, Women, Sport, Heritage, Touch), price sorting, quick detail view, and direct "Buy" reservation.
- **Contact Us & Support Desk**: Service ticket inquiry form with client-side field validation, instant reset, in-app status notification (replacing `window.alert`), and live support ticket dispatch history.
- **Timepiece Bag & Order Reservation**: Interactive cart drawer supporting quantity updates, subtotal computation, and complete concierge inquiry submission.
- **Toll-Free Concierge Banner**: Prominent access to phone support `(toll free-824-526-8843)`.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Dev Server**: Vite 6
- **Styling**: Tailwind CSS v4 with bespoke Swiss luxury aesthetic
- **Icons**: Lucide React
